🧮 ChepasCalc 🌮

Uma calculadora desktop desenvolvida em Python com Tkinter, criada como parte do desafio da Imersão Dev com IA da Alura + Google.
O projeto utiliza uma interface gráfica simples, tema escuro e operações matemáticas básicas. A proposta foi experimentar a criação de uma aplicação em Python com auxílio de inteligência artificial, executar o programa e testar seu funcionamento.

✨ Funcionalidades 🌶️
Adição (+): soma dois números.
Subtração (-): subtrai um número de outro.
Multiplicação (×): multiplica dois números.
Divisão (÷): divide um número por outro.
Números decimais: permite realizar cálculos com casas decimais.
Tratamento de erros: apresenta uma mensagem quando ocorre uma divisão por zero.
Interface gráfica: possui botões para os números e operadores, além de um visor para exibir os valores e resultados.
Tema escuro: interface com cores contrastantes.

🛠️ Tecnologias utilizadas 🐍
Python | linguagem de programação.

Tkinter | biblioteca utilizada para criar a interface gráfica.

📚 Sobre o projeto
Este projeto foi desenvolvido como atividade da Imersão Dev com IA da Alura + Google.
O código foi gerado com auxílio de inteligência artificial e executado para testar as funcionalidades da calculadora.
O projeto também serve como uma oportunidade de conhecer melhor o Python e experimentar a criação de aplicações desktop.
